# TodoListApp

A simple console-based To-Do List application written in Java. This app allows users to manage tasks by adding, viewing, deleting, loading from a file, and saving tasks to a file. It also auto-saves tasks to a default file to preserve data between sessions.

## Features

- Add new tasks
- View current tasks with indexing
- Delete tasks by selecting task number
- Load tasks from a specified file
- Save tasks to a specified file
- Auto-load and auto-save tasks to a default file (`default_tasks.txt`)
- User-friendly console menu interface with input validation

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or higher installed
- Command line or IDE to compile and run Java programs

### Running the Application

1. Clone or download this repository.
2. Compile the Java source file:

javac TodoListApp.java

3. Run the application:
   
   java TodoListApp

 ####Usage
 
Follow the on-screen menu to add, view, delete, load, save tasks, or quit the program.

Tasks are automatically saved to default_tasks.txt in the working directory on exit and after modifications.

####Code Structure
*TodoListApp.java: Contains the main method and the Menu class that manages the application's logic.

*Menu class handles user interaction, task storage, and file operations.
